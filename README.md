# Gaffer Homebrew Tap

Homebrew formulas for [Gaffer](https://gaffer.sh) — test analytics and intelligence for your CI pipeline.

## Install

```sh
brew install gaffer-sh/tap/gaffer
```

Or tap first, then install:

```sh
brew tap gaffer-sh/tap
brew install gaffer
```

## Upgrade

```sh
brew upgrade gaffer
```

## Uninstall

```sh
brew uninstall gaffer
brew untap gaffer-sh/tap
```

## Source

The CLI source lives at [gaffer-sh/gaffer](https://github.com/gaffer-sh/gaffer). Releases include prebuilt binaries for macOS (Apple Silicon, Intel) and Linux (x86_64, aarch64); this tap points at those release tarballs.
